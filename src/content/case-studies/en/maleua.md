## Context and problem

Fundación Maleua needed an institutional site for presenting programs, announcements, and public information to its community and partners. The project was associated with Alaska Tech and needed a structure that separated content from presentation components.

## My contribution

I worked on the site architecture, pages generated statically with Astro, interface components, content data organization, and publishing through Vercel. The technical aim was to update information without mixing it into each page's markup.

## Architecture and decisions

Structured data feeds Astro components; the build generates HTML and CSS files published through Vercel. This separation allows content and presentation to be reviewed independently.

## Implementation and outcomes

The site uses static generation and content separated from presentation components, with publishing through Vercel. Content and interface changes can be reviewed independently.
